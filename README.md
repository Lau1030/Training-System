# Training-System
Un sistema conformado por un sensor MAX30102 que estará conectado a un ESP32 el cual a través de ESP-NOW, (que es un protocolo inalámbrico de comunicación directa desarrollado por Espressif Systems para sus microcontroladores) se comunicara con otro ESP32 el cual pasara los datos recibidos a un Display LCD para que el usuario pueda visualizar su ritmo cardiaco, oxigeno en sangre y calorías quemadas.
